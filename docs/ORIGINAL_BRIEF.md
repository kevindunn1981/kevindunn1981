> Claude we will use this session to plan an program a mobile game in Godot. It will be held in GitHub, account on this device. The name is TBA or assigned by you. It is a top down 3d game. You will need to setup a spring_arm and camera that is attached to the player's character. All elements will be procedurally constructed from  splines, primatives and/or parabolic. It will heavily use particles systems to add visual interest. The basic premise behind the game is a space ship controlled by the player using an on screen joystick. They are attacked by spline based tenticles that wave, swing and swirl from off screen. As the game progresses the tenticles grow in size and number. The player will start with a simple turret on their ship that will shoot the tenticles. Every time they kill a tenticle it will break apart and the parts will join their ship building new tenticles on their ship. Each new tenticle will shoot a laser. That way the player can move around the screen to avoid the tenticles and slowly build up power to defend their ship. There should be a GUI with the typical elements of game play. A high score and a high score board. Please record this exact message and no paraphrased development. If you need direction please refer to this message and ask questions.
